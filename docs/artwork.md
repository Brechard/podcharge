# Artwork provenance

The [app icon](../Resources/AppIcon.png) and [README banner](podcharge-banner.png) were generated with the built-in `image_gen` tool. The banner used the selected icon as a visual style and product reference. `AppIcon.icns` was made from the approved PNG using Apple `sips` and `iconutil` for standard macOS icon sizes; the artwork was not redesigned.

## App icon

`transparent_background=true`

```text
Use case: logo-brand
Asset type: square macOS app icon for PodCharge, an intentionally tiny local AirPods charging monitor.
Primary request: a beautifully restrained, readable app icon showing an open compact white wireless-earbud charging case with two distinct white silicone-tip earbuds seated inside. A tiny amber charging-status light on the front connects it to the app's seating warning.
Style/medium: precise softly sculpted 3D product illustration, satin white material, quiet soft shadows, crisp silhouette, no fussy surface detail.
Composition/framing: square canvas, one centered graphite rounded-square macOS icon tile with generous transparent corner margins, the white case fills most of the tile and remains recognizable at small sizes.
Lighting/mood: calm, neutral studio light. The small amber indicator is the only color accent.
Constraints: genuine transparent background outside the tile; no lettering, no Apple logo, no watermark, no cables, no extra objects, no UI screenshot. Make this a finished production icon rather than a presentation sheet.
```

## README banner

`transparent_background=false`

```text
Use case: logo-brand
Asset type: wide README banner artwork for the open-source macOS project PodCharge.
Input images: Image 1 is a visual style and product reference for the new banner, not an edit target.
Primary request: a refined, minimal wide project banner with the exact project name "PodCharge" and a softly sculpted white wireless-earbud charging case with two silicone-tip earbuds, matching the supplied icon's satin materials and small amber status light.
Composition/framing: wide horizontal editorial composition, balanced whitespace, the name and the case as the two clear focal points, everything within generous safe margins. Use the case as a standalone product illustration; do not repeat the rounded-square app icon tile.
Style/medium: clean 3D product artwork with crisp restrained typography, soft studio light, neutral graphite background, amber light as the only color accent. Quiet and approachable, fitting a deliberately small utility.
Text (verbatim): "PodCharge"
Constraints: no other text, no slogan, no Apple logo, no watermark, no cloud or security shield imagery, no UI mockups or invented battery readings. The whole banner should feel polished and simple.
```
